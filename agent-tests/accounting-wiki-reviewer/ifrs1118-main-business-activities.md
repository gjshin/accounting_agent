# 에이전트 점검 지시서 — 제1118호 특정 주된 사업활동 (가상 시나리오)

- 점검 대상: `accounting-wiki-reviewer` 에이전트 (`.claude/agents/accounting-wiki-reviewer.md`)
- 주제: 기업회계기준서 제1118호 '재무제표 표시와 공시' 도입 용역 — 고객 금융제공이 주된 사업활동인지 판단하고, 그에 따라 손익을 분류하는 문제
- 시나리오: 전부 가상이다. 회사명과 금액은 실제 기업과 관계없다.
- 작성 기준일: 2026-10-02 (제1118호 시행일은 2027년 1월 1일 이후 최초로 시작하는 회계연도, 문단 C1)

## 0. 사용법

### 0.1. 점검 목적

1. 에이전트가 회계위키에서 제1118호 문단을 직접 조회하고 인용을 원문과 대조하는지
2. 경영진 원안에 들어 있는 함정(매출 비중 논리, 정책 불일치, 별도재무제표 혼동, 전환 규정 혼동)을 걸러내는지
3. 감사절차 근거로 감리지적사례가 아니라 **감사기준서 문단**을 인용하는지 (2026-10-02 절차서 8단계 수정 사항 확인)
4. 근거가 없는 곳(제1118호 관련 감리지적사례 등)에서 문단이나 사례를 지어내지 않고 "근거 미확인"으로 표시하는지
5. IFRS 해석위원회 결정처럼 **아직 확정되지 않은** 자료를 확정된 것처럼 쓰지 않는지

### 0.2. 실행 방법

에이전트 절차서는 "쟁점마다 하나씩 병렬로 맡긴다"고 정한다. 아래 쟁점 3개를 각각 별도 에이전트로 동시에 실행한다.

Claude Code 세션에 다음 문장을 그대로 입력한다.

> `agent-tests/accounting-wiki-reviewer/ifrs1118-main-business-activities.md` 파일의 제1부 공통 사실관계와 제2부 쟁점 1·2·3을 읽고, 쟁점마다 accounting-wiki-reviewer 에이전트를 하나씩 병렬로 실행해. 각 에이전트에는 제1부 전체와 해당 쟁점 의뢰문만 넘기고 의뢰문 끝에 `인터뷰 생략`을 붙여. 제3부 채점 기준은 절대 넘기지 마. 세 보고서가 오면 제3부 채점 기준으로 채점해서 제4부 결과 기록표 양식으로 정리해줘.

### 0.3. 주의

- **제3부(채점 기준)는 에이전트에 넘기지 않는다.** 넘기면 정답을 보고 쓰는 시험이 된다.
- 이 시나리오는 사실관계를 충분히 준 상태의 판단력을 보는 시험이므로 `인터뷰 생략`으로 돌린다. 인터뷰 기능 자체를 점검하려면 제1부에서 '1.2 관리 체계와 대외 설명'을 빼고 `인터뷰 생략` 없이 돌린다. 이때 에이전트가 보고부문 구성과 순이자이익 지표 사용 여부를 묻는지 확인한다.
- 회계위키에는 이 주제의 실무해설(고니머신웍스·까치금융지주·채송공방 사례 등)이 있다. 이 시나리오는 그 사례들과 사실관계를 다르게 설계했으므로, 에이전트가 해설 사례의 결론을 그대로 옮겨 오면 감점 대상이다.

## 제1부. 공통 사실관계 (에이전트에 전달)

### 1.1. 회사 개요

누리모빌리티 주식회사(이하 '지배기업')는 소형 전기 상용차(1톤 전기트럭)와 전기 이륜차를 만들어 국내 물류·배달 사업자에게 판매하는 유가증권시장 상장회사다. 한국채택국제회계기준을 적용하며, 2027년 1월 1일부터 시작하는 회계연도(2027년 12월 31일 결산)에 제1118호를 처음 적용한다. 조기 적용은 하지 않는다.

연결실체의 주요 구성은 다음과 같다.

| 회사 | 관계 | 사업 내용 |
|---|---|---|
| 누리모빌리티(주) | 지배기업 | 전기 상용차·이륜차 제조·판매 |
| 누리캐피탈(주) | 지분 100% 종속기업 (2021년 설립) | 여신전문금융업. 누리모빌리티 차량을 사는 고객에게 할부금융과 금융리스만 제공 |
| 누리셀파워(주) | 지분 40% 관계기업 | 배터리팩 합작법인. 연결재무제표에서 지분법 적용 |

### 1.2. 관리 체계와 대외 설명

- 연결 부문 공시의 보고부문은 '차량 제조·판매'와 '모빌리티금융' 두 개다. 모빌리티금융 보고부문은 누리캐피탈의 할부금융·금융리스 활동만으로 이루어진다. 이 구조는 2021년 누리캐피탈 설립 이후 바뀌지 않았다.
- 대표이사가 매월 검토하는 경영보고서와 분기 실적설명회(IR) 자료에는 '모빌리티금융 순이자이익'(할부·리스 이자수익 − 누리캐피탈 조달 이자비용 − 신용손실)이 핵심 지표로 실린다.
- 누리캐피탈은 여신전문금융업 감독규정에 따라 유동성 확보용 예치금을 **별도 계좌**로 관리한다. 이 예치금은 현금성자산으로 분류되며 다른 자금과 섞이지 않아 구분이 가능하다.
- 누리캐피탈의 조달은 여신전문금융회사채(여전채)와 은행 차입금이며, 조달 자금은 전액 할부·리스 실행에 쓰인다.
- 지배기업은 누리캐피탈에 자금을 대여하거나 보증하지 않는다. 지배기업의 시설자금 차입금은 공장 증설에만 쓰였고 사용처가 확인된다. 지배기업의 현금성자산은 제조 운영자금이다.
- 지배기업은 정상 영업 과정의 외상 매출채권 외에 고객에게 직접 금융을 제공하지 않는다.

### 1.3. 2027년 연결 손익 관련 금액 (단위: 억원)

| 번호 | 항목 | 발생 회사 | 금액 |
|---|---|---|---|
| ① | 차량 제조·판매 부문 영업손익 (아래 ②~⑨ 항목을 제외한 금액) | 지배기업 | 410 |
| ② | 할부금융·금융리스 이자수익 | 누리캐피탈 | 512 |
| ③ | 할부·리스채권 기대신용손실 | 누리캐피탈 | (64) |
| ④ | 여전채·은행 차입금 이자비용 | 누리캐피탈 | (236) |
| ⑤ | 규제 유동성 예치금(현금성자산) 이자수익 | 누리캐피탈 | 9 |
| ⑥ | 현금성자산 이자수익 | 지배기업 | 21 |
| ⑦ | 시설자금 차입금 이자비용 | 지배기업 | (48) |
| ⑧ | 리스부채 이자비용 7, 확정급여부채 순이자 5 | 지배기업 | (12) |
| ⑨ | 누리셀파워 지분법이익 | 지배기업 | 33 |
| | 법인세비용차감전순이익 | | 625 |

- 연결 매출 6,400억원 가운데 누리캐피탈 이자수익(②)은 8%다.
- 2026년(비교기간)에도 위 구조와 관리 체계가 같았다.

### 1.4. 지배기업 별도재무제표 관련 사항 (단위: 억원)

- 지배기업은 별도재무제표에서 누리캐피탈 투자주식과 누리셀파워 투자주식을 모두 **원가법**으로 회계처리한다.
- 2027년 누리캐피탈로부터 배당금 60, 누리셀파워로부터 배당금 15를 받았다.
- 별도재무제표의 부문 정보는 '차량 제조·판매' 단일 부문이며, 지배기업은 종속기업 투자를 성과 지표로 관리하지 않는다.
- 별도재무제표에도 ⑥ 현금성자산 이자수익 21, ⑦ 시설자금 차입금 이자비용 48, ⑧ 리스·확정급여 이자 12가 그대로 있다.

### 1.5. 경영진 원안 (재무팀장 제안)

1. **고객 금융제공은 주된 사업활동이 아니다.** 누리캐피탈 이자수익은 연결 매출의 8%에 불과하고, 본업은 차량 제조다. 따라서 할부·리스 이자수익(②)과 신용손실(③)은 지금처럼 매출·영업비용으로 두되, 누리캐피탈 조달 이자(④)는 재무 범주로, 규제 예치금 이자(⑤)는 투자 범주로 분류한다.
2. 지배기업 현금성자산은 영업 운영자금이므로 그 이자(⑥)는 **영업** 범주로, 시설자금 차입금 이자(⑦)는 **재무** 범주로 분류한다.
3. 리스부채·확정급여부채 이자(⑧)는 재무 범주, 지분법이익(⑨)은 투자 범주로 분류한다.
4. 손익계산서에는 영업손익과 재무손익및법인세비용차감전손익을 모두 표시한다.
5. **별도재무제표**도 연결과 같은 원칙으로 작성한다. 지배기업은 그룹의 금융 사업을 지배하므로 누리캐피탈 배당금 60을 영업 범주로, 누리셀파워 배당금 15는 투자 범주로 분류한다. 현금 이자(⑥)는 연결과 같이 영업으로 둔다.
6. 2026년 비교기간은 주된 사업활동 평가를 2027년부터 전진 적용하는 것이므로 **재작성하지 않는다.**

## 제2부. 쟁점별 의뢰문 (에이전트에 하나씩 전달)

### 쟁점 1 — 연결재무제표: 고객 금융제공이 주된 사업활동인가, 그리고 전환 공시

> 제1부 사실관계를 바탕으로, 누리모빌리티 **연결재무제표**에서 고객 금융제공이 제1118호상 주된 사업활동인지 판단하고, 경영진 원안 1번(매출 비중 8% 논리)과 6번(비교기간 미재작성)의 타당성을 검토해 줘. 그 결과에 따라 항목 ②~⑤의 범주를 정하고, 제1118호 최초 적용 시 2026년 비교기간 처리와 주석 공시 사항을 정리해 줘. 감사인이 이 판단을 검증하기 위해 수행할 감사절차도 포함해 줘.

### 쟁점 2 — 연결재무제표: 무관 현금·무관 부채의 정책 선택과 중간합계 표시

> 제1부 사실관계를 바탕으로, 누리모빌리티 **연결재무제표**에서 고객 금융제공이 주된 사업활동이라고 결론 내린 경우를 전제로, 지배기업 현금성자산 이자(⑥)와 시설자금 차입금 이자(⑦)를 어느 범주로 분류할 수 있는지 검토해 줘. 경영진 원안 2번(현금 이자는 영업, 차입금 이자는 재무)이 허용되는지, 선택 가능한 대안별로 영업손익·재무손익및법인세비용차감전손익·법인세비용차감전순이익이 각각 얼마가 되는지 표로 보여 줘. 항목 ⑧·⑨의 분류와 원안 4번(중간합계 표시)도 함께 검토하고 감사절차를 포함해 줘.

### 쟁점 3 — 지배기업 별도재무제표: 주된 사업활동 평가와 배당금 분류

> 제1부 사실관계를 바탕으로, 누리모빌리티 **별도재무제표**에서 고객 금융제공 또는 자산 투자(종속기업·관계기업 투자)가 주된 사업활동인지 판단하고, 경영진 원안 5번(연결과 같은 원칙 적용, 누리캐피탈 배당금 영업 분류, 현금 이자 영업 분류)의 타당성을 검토해 줘. 별도재무제표의 배당금 60·15, 현금 이자 21, 차입금 이자 48, 리스·확정급여 이자 12의 범주를 정하고, 연결과 결론이 달라지는 부분과 그 이유를 정리해 줘. 감사절차를 포함해 줘.

| 함정 ③ 비교기간 | 제1118호는 **소급 적용**. 2026년 비교기간을 재작성한다. 문단 B41의 전진 적용은 평가 결과가 **바뀐 경우**의 규정이며 최초 적용과 무관. 이 회사는 2021년 이후 구조가 같아 평가 변경 자체가 없음 | 문단 C2, B41 |
| 차이조정 공시 | 2026년 손익계산서 별도표시항목별로 재작성 금액과 종전 제1001호 표시 금액의 차이조정 공시 | 문단 C3 |
| 주된 사업활동 공시 | 고객에게 금융을 제공하는 것이 주된 사업활동이라는 사실 공시 | 문단 51⑵ |
| 가점 | 2027년 분기·반기 재무제표의 차이조정 공시 언급 | 문단 C4, C5 |

### 3.2. 쟁점 2 기대 결론

**결론: 경영진 원안 2번(현금 이자 영업 + 차입금 이자 재무)은 허용되지 않는다. 무관 현금 정책과 무관 부채 정책은 같은 방향이어야 한다. 선택지는 아래 A 또는 B 두 가지뿐이다.**

| 판단 포인트 | 기대 내용 | 근거 |
|---|---|---|
| 무관 현금 ⑥ | 고객 금융제공과 관련 없는 현금 → 영업·투자 중 회계정책 선택 | 문단 56⑵㈏ |
| 무관 부채 ⑦ | 고객 금융제공과 관련 없는 자금조달 부채 → 영업·재무 중 회계정책 선택 | 문단 65⑴㈏ |
| 함정 ④ 정책 불일치 | 두 정책은 서로 일관되어야 함 → (투자·재무) 또는 (영업·영업)만 가능 | 문단 56⑵㈏, 65⑴㈏ 상호 참조 |
| ⑧ 리스·확정급여 이자 | 자금조달에만 관련되지는 않는 부채 → 정책과 무관하게 재무 | 문단 59⑵, B53⑶⑷, 61, 65⑵㈎ |
| ⑨ 지분법이익 | 지분법 적용 투자 → 항상 투자 범주 | 문단 53⑴, 55⑴, B38, B42 |
| 함정 ⑤ 중간합계 | 대안 B(무관 부채 영업)를 고르면 재무손익및법인세비용차감전손익을 표시할 수 없음. 추가 중간합계를 둔다면 '재무손익차감전이익' 같은 명칭 금지 | 문단 69⑵, 73, 74 |
| 가점 | 무관 부채 정책이 누리캐피탈 밖의 지배기업 차입금에도 그룹 전체로 적용된다는 IFRS 해석위원회 2026년 6월 **잠정** 안건결정을 언급하되, 잠정·미확정임을 명시 | 해석위원회 잠정결정 (확정 전) |

기대 수치 표 (단위: 억원). 에이전트 보고서의 숫자가 이와 일치해야 한다.

| 항목 | 경영진 원안 | 대안 A (현금 투자 · 부채 재무) | 대안 B (현금 영업 · 부채 영업) |
|---|---|---|---|
| ① 제조·판매 영업손익 | 410 | 410 | 410 |
| ② 할부·리스 이자수익 | 512 | 512 | 512 |
| ③ 기대신용손실 | (64) | (64) | (64) |
| ④ 누리캐피탈 조달 이자 | 재무 | (236) | (236) |
| ⑤ 규제 예치금 이자 | 투자 | 9 | 9 |
| ⑥ 지배기업 현금 이자 | 21 | 투자 | 21 |
| ⑦ 지배기업 차입금 이자 | 재무 | 재무 | (48) |
| **영업손익** | **879** | **631** | **604** |
| 투자 범주 (⑤·⑥·⑨ 중 해당분) | 42 (9+33) | 54 (21+33) | 33 |
| **재무손익및법인세비용차감전손익** | 921 | **685** | **표시 불가** (선택 시 '영업손익과 지분법손익' 등 637) |

### 3.3. 쟁점 3 기대 결론

**결론: 별도재무제표는 별도로 평가한다. 지배기업 별도재무제표에서는 고객 금융제공도, 종속기업·관계기업 투자도 주된 사업활동이 아니다. 경영진 원안 5번은 받아들일 수 없다.**

| 판단 포인트 | 기대 내용 | 근거 |
|---|---|---|
| 평가 단위 | 보고기업 전체 관점에서 보고기업마다 평가. 연결과 별도 결론이 다를 수 있음 | 문단 B37, BC99 |
| 고객 금융제공 | 지배기업 자체는 고객 금융을 제공하지 않음 → 별도재무제표에서 주된 사업활동 아님 | 문단 B37, BC99 |
| 자산 투자 | 원가법 종속기업·관계기업 투자는 평가 대상. 단일 제조 부문이고 투자를 성과 지표로 관리하지 않으므로 증거 없음 | 문단 B38, B33~B36 |
| 함정 ⑥ 누리캐피탈 배당금 60 | 별도재무제표의 원가법 종속기업 투자 → 투자 범주 (영업 아님) | 문단 53⑴, 54, B44⑶, B47⑵ |
| 누리셀파워 배당금 15 | 별도재무제표의 원가법 관계기업 투자 → 투자 범주 | 문단 53⑴, B43⑶ |
| 함정 ⑦ 현금 이자 21 | 별도재무제표에는 특정 주된 사업활동이 없으므로 정책 선택권 자체가 없음 → 투자 범주 | 문단 53⑵, 56, B39 |
| 차입금 이자 48 | 재무 범주 | 문단 59⑴, 60 |
| 리스·확정급여 이자 12 | 재무 범주 | 문단 61 |
| 연결과의 차이 | 현금 이자 21이 연결(대안 B 선택 시)에서는 영업, 별도에서는 투자처럼 결론이 달라질 수 있으며 이는 정상. 연결 정책을 별도에 그대로 옮기면 안 됨 | 문단 B37, BC98, BC99 |

### 3.4. 공통 품질 기준 (세 보고서 모두 적용)

| 번호 | 점검 항목 | 통과 기준 |
|---|---|---|
| Q1 | 보고 양식 | 절차서의 최종 보고 양식 10개 항목을 모두 갖춤 |
| Q2 | 사실과 가정 구분 | 제공된 사실과 에이전트가 둔 가정을 구분해 적음 |
| Q3 | 출처 URL | 모든 기준서 문단·질의회신·실무해설 근거에 회계위키 URL이 붙음 |
| Q4 | 인용 검증 | 마지막 항목에 검증 문구 수 / 수정 문구 수 / 근거 미확인 항목이 적혀 있음. 검증자가 인용 2~3개를 골라 회계위키 원문과 직접 대조했을 때 일치 |
| Q5 | 감사기준 인용 | 감사절차 근거가 **감사기준서 문단**(예: 315 위험평가, 330 위험 대응, 710 비교정보, 580 서면진술, 701 핵심감사사항 등)으로 인용됨. 감리지적사례를 감사기준 근거처럼 쓰면 실패 |
| Q6 | 감리사례 처리 | 제1118호 시행 전이라 직접 관련 감리지적사례가 없다는 점을 밝히고, 유사 사례는 "참고만"으로 표시하거나 "근거 미확인"으로 처리. 존재하지 않는 사례를 지어내면 즉시 실패 |
| Q7 | 잠정 자료 표시 | IFRS 해석위원회 2026년 6월 결정이나 회계기준원 정착지원 TF 논의를 쓴다면 잠정·비공식임을 명시 |
| Q8 | 분개 | 표시(범주) 문제이므로 인식·측정 분개가 없음을 밝히고 범주 재분류표로 대신함. 불필요한 분개를 지어내면 감점 |
| Q9 | 세무 | 범주 분류만 바뀌고 과세소득은 달라지지 않는다는 취지로 짧게 처리. 근거 없이 세무 결론을 길게 쓰면 감점 |
| Q10 | 용어 | 약어 없이 풀어 씀 (한국채택국제회계기준, 내부회계관리제도 등) |
| Q11 | 실무해설 사례 복사 여부 | 회계위키 실무해설의 다른 회사 사례 결론·숫자를 본건 숫자인 것처럼 옮기지 않음 |

### 3.5. 판정 기준

| 판정 | 기준 |
